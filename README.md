# Toán Thầy Minh

Trang giới thiệu khóa học luyện thi vào lớp 6 trường tiên tiến, hội nhập.

- `index.html`: nội dung trang
- `style.css`: giao diện
- `hoc/`: khu học tập (đăng nhập, khóa học, tài liệu, quản lý tài khoản)
- `apps-script/`: máy chủ Google Apps Script và [hướng dẫn cài đặt](apps-script/HUONG-DAN.md)
