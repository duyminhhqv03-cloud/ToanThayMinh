# Toán Thầy Minh

Trang giới thiệu khóa học luyện thi vào lớp 6 trường tiên tiến, hội nhập.

- `index.html`: nội dung trang
- `style.css`: giao diện
- `hoc/`: khu học tập (đăng nhập, khóa học, tài liệu, quản lý tài khoản, đấu cả lớp)
- `apps-script/`: máy chủ Google Apps Script, [hướng dẫn cài đặt](apps-script/HUONG-DAN.md) và [hướng dẫn cài Firebase (Đấu cả lớp)](apps-script/FIREBASE.md)
